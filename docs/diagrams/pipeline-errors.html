Where the analyze request can fail

Checks run cheapest first, so a request spends no YouTube quota or Groq tokens until it has passed the rate limit and validation. 504 can fire at any step once the time budget runs out. A failed batch is not an error: it is dropped and the request still returns 200 as long as one comment was classified. Happy-path stages: pipeline-overview.html.
